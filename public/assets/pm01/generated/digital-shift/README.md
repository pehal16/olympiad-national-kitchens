# PM01 Digital Shift Generated Assets

This directory is reserved for final teacher-approved PM01 digital-shift assets.

Rules:

- Do not connect generated images to official exam questions before teacher approval.
- Store preview/final images by shop:
  - `vegetables/`
  - `fish/`
  - `meat/`
  - `poultry/`
  - `complex/`
- Use the target paths exposed by `/api/pm01/public/exam` in `digitalShift.packages[].previewAssets[]`.
- Every image must be visually inspected before it is referenced by PM01 questions.
- Reject images with cooked-looking products, restaurant plating, labels/logos, random text, unclear raw material shape, anatomically strange poultry/rabbit, or misleading semi-finished forms.

Current status: preview slots are planned, final generated assets are not connected yet.
