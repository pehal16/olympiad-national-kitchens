ПРОБНЫЙ ЗАПУСК ОЛИМПИАДЫ НА WINDOWS

1. Скачайте ZIP и распакуйте его целиком в обычную папку, например C:\OlympiadTrial.
2. Откройте папку и дважды щёлкните start-olympiad.cmd.
3. Дождитесь сообщения «Пробная олимпиада запущена». Браузер откроется автоматически.
   Адрес на этом компьютере: http://127.0.0.1:3100/
4. Оставьте окно сервера открытым. Остановка: Ctrl+C.
5. Для следующего запуска откройте тот же start-olympiad.cmd. Ответы сохраняются.

Node.js включён в комплект; Git, npm, права администратора и установка программ не нужны.
Первый запуск создаёт отдельную базу и случайный пароль организатора.
Данные находятся в %LOCALAPPDATA%\GKTSOlympiadTrial\v1.
Пароль панели: файл «Организатор.txt» в этой папке. Не отправляйте его участникам.
Отчёт без пароля: launch-report.json. Его можно передать для проверки запуска.

ПРОВЕРКИ
backup-olympiad.cmd создаёт и проверяет резервную копию локальной базы.
test-60.cmd запускает 60 синтетических участников на другом порту и в отдельной базе.
Сохраните отчёт load-report.txt, адрес которого появится в конце проверки.
Проверка может сообщить превышение задержки: это требует разбора, а не удаления данных.

Это пробная копия. Она не импортирует реальные попытки с основного сайта.
36 заданий, 150 баллов, 18 минут 45 секунд; Т1–Т4 по 30 секунд, Т5 по 45 секунд.
Свидетельство доступно после личного финиша; заработанное меню — после публикации организатором.
Для повторного ручного прохождения используйте другое тестовое имя: одна попытка на человека.
Итоги: в панели организатора остановите новые старты, дождитесь завершения попыток и опубликуйте.
Публикация завершает тестовое проведение; до новой репетиции сохраните базу и обсудите создание нового проведения.

Комплект слушает только 127.0.0.1 и не открывает брандмауэр, домен или доступ из интернета.
Подключение других устройств и olympiada.gorlkts.ru выполняется отдельным следующим шагом.
Не запускайте .cmd прямо внутри ZIP; не перемещайте и не удаляйте папку данных для решения ошибки.
Оригинальный Node.js: https://nodejs.org/ ; лицензия: runtime\NODE-LICENSE.txt.
