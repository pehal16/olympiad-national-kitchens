# Пилот текстового помощника на компьютере колледжа

В рабочем кабинете кнопка **Создать тест с ИИ** принимает одно поручение. Например, «Составь 10 вопросов по дрожжевому тесту для первого курса». Помощник предлагает название теста и вопросы с четырьмя вариантами и одним правильным ответом. В поручении можно указать от 1 до 20 вопросов. По умолчанию их десять. Проверьте предпросмотр и нажмите **Создать тест**, чтобы сохранить редактируемый черновик. В открытом проекте **Задания → ИИ-помощник** добавляет готовые вопросы в выбранный тур.

Первый технический пилот готовил один вопрос по учебному фрагменту с дословной цитатой. Проверки этой версии описаны ниже.

## Первый запуск на iRU

Целевой компьютер — iRU 510B7GP с NVIDIA RTX 5070. Codex запускает команды на выбранном устройстве. После подключения устройства выберите его как место выполнения задачи и проверьте имя ПК и GPU. На iRU откройте отдельную рабочую копию ветки `codex/ollama-iru-pilot`. Используйте проверенный Node.js 24 из Windows-комплекта олимпиады или установленный Node 24.

Из корня рабочего каталога:

```powershell
$launcher = '.\constructor\ops\windows-assistant\Start-TeacherAssistant.ps1'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File $launcher -Mode Preflight
powershell.exe -NoProfile -ExecutionPolicy Bypass -File $launcher -Mode Install
```

Если Node.js находится только в распакованном Windows-комплекте и не запущен, передайте `-NodeExe` с его полным путём. Установочный каталог по умолчанию — `%LOCALAPPDATA%\GKTSOllamaAssistant`. При нехватке места можно выбрать отдельную папку на другом локальном диске через `-InstallDir` и сохранить тот же путь для следующих команд.

Скрипт сверяет SHA-256 [официального архива Ollama 0.40.17](https://github.com/ollama/ollama/releases/tag/v0.40.17). Повторный запуск продолжает загрузку неполного архива и использует уже скачанную модель. Для первого замера выбран [Qwen3.5 9B Q4_K_M](https://ollama.com/library/qwen3.5:9b-q4_K_M). Новая установка требует от 16 ГиБ свободного места. Модель и программа загружаются на iRU.

Ollama использует отдельный каталог моделей, отключает облачные функции и слушает `127.0.0.1:11435`. Первый контрольный прогон делает два запроса на синтетическом учебном фрагменте. В `pilot-report.json` остаются имя ПК, GPU, версия драйвера, время обоих запросов и объём памяти модели на GPU из Ollama. Указанный объём относится к загруженной модели, а не к пиковому расходу видеопамяти. Задача `GKTS-TeacherAssistant-Ollama` создаётся после прохождения обоих запросов и запускается при входе этого пользователя Windows. Повторная проверка — `-Mode Check`. Остановка пилота — `-Mode Stop`.

## Подключение после локальной проверки

1. Прочитайте `pilot-report.json` на iRU и оцените ответы модели. При ошибке используйте локальный каталог `logs` и перепроверьте драйвер, загрузку модели и использование GPU.
2. Разверните пилот сначала на отдельной копии службы конструктора. Для активации задайте `CONSTRUCTOR_ASSISTANT_WORKER_TOKEN` в защищённой конфигурации службы. Рабочий ключ состоит из 32 случайных байтов в base64url, 43 символов. Он даёт доступ только к двум HTTP-методам работы с очередью. Храните его отдельно от исходников и от паролей преподавателей.
3. На iRU запустите установленный скрипт с `-Mode Connect -CabinetOrigin <HTTPS origin кабинета>`. Он запросит ключ скрытым вводом и запишет его с защитой DPAPI текущей учётной записи. Рабочий процесс сам обращается к кабинету по HTTPS. Если системный маршрут до кабинета недоступен, но известен рабочий сетевой интерфейс, укажите его имя, например `-CabinetInterface Ethernet`. Имя сохраняется в настройках помощника, а IPv4 интерфейса определяется при каждом обращении к кабинету.
4. Войдите как преподаватель, нажмите «Создать тест с ИИ» и введите одно поручение. Проверьте число вопросов, варианты и ключи в предпросмотре. Сохраните черновик и проверьте его после перезагрузки. В проекте откройте «Задания → ИИ-помощник» и проверьте добавление нового набора в выбранный тур. Отключение пилота в кабинете выполняется удалением `CONSTRUCTOR_ASSISTANT_WORKER_TOKEN` из конфигурации и перезапуском службы конструктора.

Запросы и готовые ответы до добавления хранятся в памяти службы, поэтому при её перезапуске черновик нужно сформировать повторно. Фрагменты учебных материалов и результаты проходят через кабинет и iRU. Для пилота используйте фрагменты без персональных данных. Запросы помощника не зависят от публичной демоверсии участников. Для обычного редактирования, проведения и выдачи документов модель не требуется.
