## Сохранённая проверка выдачи после личного финиша

Последнее указание владельца от 07.10.2026 заменяет прежнее ожидание общей публикации для свидетельства. Документ доступен владельцу после завершения своей попытки; показывает сохранённый общий результат из 150 и приказ № 199 / 05.10.2026. Правильные ответы студентам не показываются и после общей публикации. Персональный стол, реакции и рейтинг сохраняют прежнюю общую публикацию.

Серверный запрос `/api/public/attempts/:id/certificate` проверяет токен владельца и завершение, обрабатывает истечение времени. Возвращает имя/наставника, приказ и только общий балл: нет вопросов, решений, оценок заданий, вариантов и чужих данных. Ответ имеет `private, no-store`, API не попадает в service worker. Старые попытки сохраняют прежнюю настройку показа баллов. `review: []` оставлен для совместимости уже открытых старых страниц, эталонные объяснения удалены из студенческой коллекции.

Локальные проверки: 275/275 тестов, Cloudflare build и PM01 на полном сервере 3217 проходят. В HTTP проверены активная попытка (409), отсутствующий/чужой токен (401), досрочное завершение с 2 из 150, повторное чтение, истечение времени с 0 из 150, скрытый общий стол при открытом входе, неизменность свидетельства после публикации. Проверяется сохранённый балл, включая отличие от автоматической оценки; баллы из банка повторно не начисляются.
