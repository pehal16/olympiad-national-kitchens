# Как разместить олимпиаду

## Рекомендуемый вариант

Для прохождения из разных учебных заведений лучше использовать **веб-версию на одном сервере**, а не `exe`.

Причина:

- все ответы идут в одно хранилище;
- не нужно рассылать и обновлять файлы по учреждениям;
- не теряются результаты;
- администратор видит всех участников в одной панели;
- проще формировать единый протокол.

## Как разместить на сайте колледжа

### Вариант 1. Отдельный сервер или VPS

Это лучший путь.

1. Установить `Node.js` на сервере.
2. Скопировать папку проекта на сервер.
3. Выполнить в папке проекта:

```bash
npm start
```

4. Настроить домен или поддомен, например:

```text
olymp.gkts.example.ru
```

5. На сайте колледжа поставить кнопку или баннер со ссылкой на этот адрес.

Для вашего сайта на Tilda:

- саму олимпиаду лучше держать на отдельном адресе, например `olymp.gorlkts.ru` или на внешнем сервере;
- на Tilda сделать отдельную страницу «Олимпиада»;
- на этой странице разместить кнопку `Пройти олимпиаду`;
- кнопка должна вести на адрес запущенного Node-сервера.

### Вариант 2. Если основной сайт не поддерживает Node.js

Тогда саму олимпиаду лучше не загружать внутрь сайта как обычные HTML-страницы, а:

- разместить её на отдельном сервере;
- на сайте колледжа оставить кнопку «Пройти олимпиаду»;
- при необходимости встроить через `iframe`, если это разрешит администратор сайта.

Для Tilda это наиболее реалистичный путь, потому что текущий проект использует серверную логику `Node.js`, а не только статические страницы.

## Почему не рекомендую EXE как основной формат

`exe` подходит только если:

- олимпиада проходит локально в одном учреждении;
- не нужна единая база на сервере;
- не нужна централизованная ручная проверка.

Для межучрежденческого формата `exe` хуже, потому что:

- результаты будут разрозненными;
- обновление банка заданий станет неудобным;
- потребуется дополнительная серверная логика всё равно.

## Когда EXE всё-таки имеет смысл

Только как локальная копия для демонстрации или офлайн-запуска в одном кабинете.

Для общего проведения и сбора результатов правильный путь — веб-версия.
