## Телефоны

На мобильных браузерах требуется активная видимая вкладка, без обязательного Fullscreen API. Уход в другую вкладку/приложение и закрытие страницы фиксируются существующим журналом; показ клавиатуры не считается выходом из fullscreen. На компьютерах прежнее требование fullscreen и контроль фокуса сохраняются. Баллы от этих событий автоматически не уменьшаются. Это обновление способа управления; состав, оценивание и время заданий не меняются.

- Крупные сенсорные цели и поля от 16 px; закреплённая компактная полоса таймеров, переход к началу новой страницы.

## Общая база и резерв

По отдельному решению пользователя официальные новые попытки используют одну Cloudflare D1. ПК обслуживает основной интерфейс и пересылает разрешённые participant API в `olympiad-gkts.pages.dev`, без Cloudflare административных ключей на ПК. Кабинет официального проведения: **https://olympiad-gkts.pages.dev/admin.html**, с существующим паролем этого кабинета.

Кнопка резервного адреса переносит идентификатор, токен владельца, текущий черновик и очередь неподтверждённых ответов через URL fragment. Фрагмент удаляется до запросов API; принимающая сторона проверяет владение до записи доступа. Часы не перезапускаются. Перезагрузка при недоступном API исходного адреса сохраняет возможность перейти по ранее подтверждённой локальной ссылке восстановления. Персональные API не кэшируются. Worker кэширует только оболочку/публичные ресурсы; admin-файлы исключены из обязательной установки.

Исходная SQLite ПК и её постоянные секреты сохраняются как архив пробного запуска. Они не считаются автоматически перенесёнными в D1. Обновление не выполняет переключение, если в SQLite есть неистёкшие активные попытки. Не объединять разные рабочие базы по совпадающим ФИО и не удалять прежние результаты.

Подготовленный шлюз Nginx кэширует только публичные изображения с одной холодной загрузкой на ключ; API-кэш выключен, персональные заголовки в image upstream не передаются. Конфигурацию необходимо проверить `nginx -t` на самом шлюзе до применения. Её наличие в Git не доказывает установку на VPS.
