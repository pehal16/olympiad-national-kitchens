# Доступность олимпиады для участников в РФ

Статус: подготовка переноса, 23 сентября 2026 года. В Timeweb Cloud создан отдельный проект «Олимпиада — Национальные кухни мира»; VPS ещё не заказан, домен не выбран. Текущий рабочий адрес остаётся `https://olympiad-gkts.pages.dev`. Актуальный порядок работ — в `docs/timeweb-olympiad-runbook.md`.

## Почему нужен перенос всего приложения

Cloudflare сообщает об ограничении трафика к обслуживаемым им сайтам у части провайдеров РФ. Это сетевой уровень: смена дизайна, DNS-имени или добавление ещё одного домена к Cloudflare Pages не даёт гарантии доступности. Источник: https://developers.cloudflare.com/support/troubleshooting/general-troubleshooting/service-disruption/ .

Участник использует не только HTML и изображения, но и API регистрации, запуска, сохранения каждого ответа и завершения. Поэтому перенос только статических файлов оставит критические запросы на Cloudflare. Нужны веб-сервер, API и база данных на площадке, доступной из сетей участников в РФ.

## Обязательные работы до переключения

1. Проверить подготовленный отдельный сервер олимпиады на VPS Timeweb: SQLite/WAL, атомарный старт, версионное сохранение ответов и идемпотентный журнал событий. Текущий файловый JSON-адаптер не выдержал целевую нагрузку и для официального запуска непригоден. Локальные 40/60-прогоны нового адаптера прошли, но не заменяют тест на VPS.
2. Перенести без удаления только относящиеся к олимпиаде действующие попытки, ответы, события и настройки, если они есть. Выполнить контроль количества записей и выборочную сверку до и после импорта. Учебные данные и PM01 остаются на Cloudflare; секреты не размещать в репозитории.
3. Развернуть HTTPS и домен, настроить ежедневную копию SQLite вне VPS, проверить восстановление, мониторинг доступности и ошибок API, ограничение частоты запросов и короткое окно старта. Снимок одного VPS не заменяет проверенную копию базы.
4. Проверить с настоящих подключений РФ: колледж, мобильные операторы и минимум две внешние сети. Проверять загрузку страницы, изображений и 3D, регистрацию, старт, несколько ответов, восстановление после обрыва, журнал преподавателя и завершение.
5. Провести репетицию 60 одновременных участников с отдельной тестовой базой: синхронный старт, все вопросы, сохранение ответов, обрывы связи, события контроля и завершение. Зафиксировать ошибки, p95 задержки ответов, CPU, RAM и дисковую задержку; при нехватке запаса повысить тариф до официального запуска. Переключать основной адрес только после проверки данных и репетиции; старый Cloudflare-адрес оставить временным архивным маршрутом без независимых новых попыток.

## Контроль участия

Открытая регистрация позволяет любому студенту подать данные. Сервер проверяет формат ФИО и показывает подтверждённые старты преподавателю. Эти проверки не доказывают личность: перед официальным допуском нужен очный контроль документа или подтверждение преподавателем в аудитории. Если в дальнейшем потребуется удалённый допуск, нужен отдельный проверяемый идентификатор.

Браузер фиксирует уход с вкладки, потерю фокуса, выход из полного экрана, попытку вставки и полученную клавишу Print Screen. Операционная система может сделать снимок без события в браузере; фото экрана другим устройством веб-страница не обнаруживает. Для строгого экзаменационного режима нужны очное наблюдение и управляемые компьютеры/режим киоска.
