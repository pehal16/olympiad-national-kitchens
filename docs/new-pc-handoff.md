## Как открыть работу на новом компьютере

1. Клонируйте репозиторий **в отдельную папку исходников**, например `C:\CodexProjects\olympiad-national-kitchens`. Не превращайте распакованный архив в Git-репозиторий: в нём лежат runtime и зафиксированная старая сборка.
2. Откройте эту локальную папку как проект Codex на стационарном ПК. Для работы с запущенным экземпляром добавьте папку `OlympiadTrial` дополнительной папкой проекта, когда нужен доступ к ней. Основной папкой остаётся Git-копия с `AGENTS.md`.
3. Начните локальный чат на **этом компьютере**. Подключение GitHub или выбор облачной задачи сами по себе не дают доступ к работающему на ПК серверу.
4. Передайте новой сессии короткое задание из следующего раздела. Она прочитает закреплённую историю и начнёт с проверки существующего запуска.

Если Git уже установлен, пример для новой, ещё не существующей папки:

```powershell
$olympiadProjects = Join-Path $env:USERPROFILE 'CodexProjects'
New-Item -ItemType Directory -Path $olympiadProjects -Force | Out-Null
git clone https://github.com/pehal16/olympiad-national-kitchens.git (Join-Path $olympiadProjects 'olympiad-national-kitchens')
```

Распакованный комплект включает собственный Node.js. Это не доказывает, что глобальные `node`, `npm.cmd` и Git установлены. Для разработки сначала проверьте доступные инструменты; проект проверен на Node 24.18.0, локальный SQLite-запуск требует 24.15+. Для тестов/сборки в Git-копии используются зависимости из `npm ci`.

Работа с локальными папками и выбор места выполнения описаны в [документации проектов](https://learn.chatgpt.com/docs/projects) и [режимов Codex](https://learn.chatgpt.com/docs/environments/modes). Конкретный интерфейс приложения может отличаться; не утверждайте наличие невидимой кнопки и не повторяйте старую ошибочную инструкцию про переключатель внизу существующего чата.

## Что найти при первом осмотре

Сначала выполните стартовый протокол из `AGENTS.md`:status, pull без принудительного сброса, последние коммиты, память. Любые незавершённые изменения сохраняйте.

Проверьте устройство и локальный сервер:

```powershell
Get-CimInstance Win32_ComputerSystem | Select-Object Name, Manufacturer, Model, TotalPhysicalMemory
Get-CimInstance Win32_Processor | Select-Object Name, NumberOfCores, NumberOfLogicalProcessors
Invoke-RestMethod http://127.0.0.1:3100/api/health
```

Ожидаемый health: `ok:true`, `mode:olympiad-only`, `storage:sqlite`. Сверьте процесс, его рабочие файлы и порт;не запускайте второй сервер на занятом 3100 и не завершайте посторонние процессы. Точный путь распакованной папки пользователь пока не сообщил; найдите его по работающему процессу или локальным файлам, а не выдумывайте путь.

## Сборка архива и свежие исходники

Уже выданный [Windows-комплект](https://github.com/pehal16/olympiad-national-kitchens/releases/tag/windows-trial-2026-10-13) зафиксирован на **e032eaa**:Node 24.18.0, 233222733 байта, 1578 файлов. SHA-256 ZIP:`f2abd73a130b1f3285135b727b701b75cd41f2a782df8fbfcbc82c3ea7490450`.

В `main` после него опубликовано новое оформление свидетельства:пара логотипов, печать немного поверх номера/даты приказа, редакция`seal2`. Поэтому распакованный архив не является автоматически последней версией сайта. Сверяйте его `package-manifest.json` с актуальным Git. Переход на новые исходники выполняйте после резервной копии, сохранения секретов и проверки совместимости;не заменяйте уже выданные варианты.

В архиве:

- `start-olympiad.cmd` — запуск, открытие браузера;окно остаётся открытым, остановкаCtrl+C;
- `backup-olympiad.cmd` — согласованная копия с`integrity_check`, количествами иSHA-256;
- `test-60.cmd` —60 синтетических участников на другом порту и в отдельной базе;
- `scripts/windows-trial.js` — тот же запускатель в текущих исходниках;
- `olympiad-server.js` — существующий сервер только олимпиады;
- `src/sqlite-d1.js` — локальный адаптер текущей модели D1;
- `scripts/build-windows-trial.js` — воспроизводимая сборка ZIP из точного коммита с подписанным Node и лицензией.

Запускатель из свежей Git-копии: `node scripts/windows-trial.js`. Он по умолчанию использует **ту же** папку данных и секреты. Перед сменой запущенного экземпляра сделайте backup и остановите только прежний пробный сервер;при необходимости независимой проверки задайте другой `--state-dir` и порт. Глобальный `npm start` — общий сервер разработки с другими модулями, его не подставляют вместо выделенного запуска.
