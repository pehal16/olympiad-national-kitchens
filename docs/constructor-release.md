## Онлайн-установка

Кабинет: [олимпиада.постовит.рф/constructor/](https://xn--80aaloaqinm.xn--b1amqadnhd.xn--p1ai/constructor/).

На существующем Timeweb-сервере установлены отдельные Node24, Chromium и служба `olympiad-constructor.service`. Файлы выпуска находятся в `/srv/olympiad-constructor/releases/<revision>`, рабочие данные — в `/srv/olympiad-constructor/data`. Служба слушает loopback3210; nginx направляет только `/constructor/` и `/api/constructor/`. Проверка конфигурации, сохранение прежнего файла, ожидание готовности и откат защищают переключение. Старый service worker исключает страницы и API конструктора.

Аудит сервера: 2 CPU, 3915 МБ RAM. Служба ограничена 900 МБ памяти, 1 CPU и 128 задачами. Синтетическая проверка использует отдельную canary-базу на том же сервере; она не добавляет попытки в рабочую базу. После последнего переключения служба активна, перезапусков 0, память процесса около 125 МиБ, доступная память хоста 1734 МБ. ## Автономный Windows-комплект

Архив: `constructor/release/Windows-1.0.0-verified.zip`, 419 408 155 байт. SHA256:

```text
ad7d2d6344c854b5173b4bb789005c0a03659445639f1b8b6279c8f37a166cf8
```

Комплект содержит Node24.18, приложение, фиксированные зависимости, собственный Chrome, локальные изображения, шрифты, лицензии, запуск и восстановление. Пользовательские данные в архив не входят. Все 12 641 файла проверены потоковым чтением ZIP по SHA256 из `checksums.json`; сервер, восстановление и интерфейс совпадают с проверенной сборкой. Рядом с ZIP сохранён файл `.sha256`.

Распаковать весь архив и открыть `Запустить.cmd`. Запуск показывает адрес кабинета и адреса локальной сети; настройка владельца использует одноразовый код из `data/Первый вход.txt`. Для доступа из сети требуется разрешить порт в Windows. При обновлении сначала остановить прежний процесс; одна папка данных используется только одним экземпляром. Новую версию распаковывать отдельно, прежнюю папку подключать через `CONSTRUCTOR_STORAGE` после резервного копирования.

Именно этот комплект запущен отдельно на 127.0.0.1:3212 и прошёл полный браузерный маршрут при блокировке внешнего интернета. Единственный сетевой origin — localhost. Подтверждены сохранение и повторное открытие проекта, публикация, мобильное прохождение, восстановление локального черновика, оба решения конфликта ответов и запрет перехода до решения конфликта, ручная оценка по критериям, утверждение наград и выпуск PDF. Ошибок страницы нет.

## Нагрузка и сохранность

Оба итоговых прогона: 100 одновременных участников, 2 000 ответов, 400 повторных запросов и 12 PDF одновременно с прохождением.

| Установка | p95 сохранения | Максимум | Потерянные ответы | Дубли |
| --- | ---: | ---: | ---: | ---: |
| Timeweb, лимит 900 МБ / 1 CPU | 489 мс | 3133 мс | 0 | 0 |
| Выдаваемый Windows-комплект | 434 мс | 564 мс | 0 | 0 |

Цель p95 до двух секунд выполнена; это не обещание такого времени для каждого запроса. Первоначальный локальный p95 2077 мс не прошёл порог и привёл к общей долговечной фиксации SQLite FULL; он не считается успешной приёмкой.

После настоящего перезапуска комплект сохранил 100 попыток и 2 000 ответов с тем же хешем содержимого. Ответы подтверждаются после фиксации SQLite; повторные запросы имеют устойчивые квитанции. Новые редакции не меняют начатые попытки. Непроверенные работы сохраняют ожидание, незавершённые — незавершённость.
