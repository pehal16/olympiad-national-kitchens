## Выпуск

Онлайн-размещение и окончательная проверка Windows-комплекта выполняются после фиксации исходников. Результаты добавляются в эту запись по фактическим квитанциям.

Обновление конструктора сначала проходит отдельную canary-установку с нагрузкой и браузером. Перед заменой действующей службы создаётся согласованный SQLite-снимок, проверяется целостность, копируются связанные медиа/документы и прежний unit. Действующая папка данных и пароли сохраняются. Существующий nginx vhost дополняется только принадлежащим конструктору include; остальные маршруты сохраняются.

## Пользовательская приёмка

Технический выпуск не подтверждает цель «три новых преподавателя самостоятельно подготовят по пять заданий за 20 минут». Для этого нужны реальные педагоги. Их участие, опыт, время и затруднения записываются при испытании, а не восстанавливаются по догадке.

Для каждого из трёх участников проверить без подсказок автора: вход по приглашению; выбор с нуля/образца; создание пяти заданий и ключей/критериев; исправление ошибки проверки; пробу; подготовку ссылки; открытие входа; просмотр результата и награды. Отдельно записать, где потребовалась помощь и какие подписи оказались непонятны.

Остаются отдельными проверками настоящие телефоны, сеть колледжа с другого устройства и физическое отключение внешнего интернета. Блокировка внешних запросов в браузере подтверждает автономность ресурсов проверенного сценария, но не настройку школьного маршрутизатора или брандмауэра. Проверка клавиатуры и размеров экрана не является заключением об универсальной пригодности для всех обучающихся с ОВЗ.
