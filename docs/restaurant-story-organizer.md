# «Ресторан путешествий. Вечер вкусов»: проведение

Основной сайт: https://olympiad-gkts.pages.dev. Кабинет: https://olympiad-gkts.pages.dev/admin.html.

## До мероприятия

По просьбе владельца свободный вход включён по умолчанию: зарегистрироваться, подтвердить правила и начать олимпиаду можно в любое время без назначения даты. Общий сценарный запуск создаётся автоматически один раз, без вымышленной даты. Одна попытка участника допускается в пределах этого запуска; повторный запрос восстанавливает ту же попытку, а завершённая попытка не даёт повторного старта.

В кабинете организатора раздел «Ресторан путешествий: проведение» показывает «Свободный вход · начать в любое время». Чтобы открыть общий финал, сначала нажмите «Остановить новые старты», затем дождитесь завершения всех активных попыток и нажмите «Опубликовать итоги». До публикации вход можно возобновить; после публикации новые старты этого запуска закрыты. Просмотр главной страницы не создаёт новый запуск вместо остановленного или опубликованного.

Для отдельного официального дня по-прежнему можно выбрать согласованную дату по Москве и нажать «Создать день». Дата и версии закрепляются при создании; изменить их через интерфейс нельзя. В пределах назначенного дня сайт использует это проведение; вне его окна действует свободный запуск с его собственным состоянием и попытками.

Вход открывается автоматически в 00:00 выбранного дня и закрывается в 00:00 следующего. Каждый студент получает полные 45 минут с момента старта. При старте в 23:59 попытка продолжится после полуночи. Вступление и общая инструкция доступны до старта; новые главы открываются без обязательных вводных кнопок. Требования действующего защищённого режима остаются: заранее проверьте полноэкранный режим в браузерах колледжа.

Проведите отдельную репетицию на реальных компьютерах и телефонах в сети колледжа. Проверьте понятность названий, трёх подсказок, четырёх вариантов заказов и операций кухни вместе со студентами и преподавателем. Автоматическая нагрузочная проверка не заменяет эту проверку содержания и оборудования. Новые равноценные варианты вопросов — отдельная содержательная работа; текущий выпуск использует действующий банк.

## Во время проведения

Панель показывает начатые, завершённые и активные попытки каждого проведения. «Остановить новые старты» запрещает только создание новых попыток. Уже начавшие сохраняют таймер и ответы, могут восстановить страницу и закончить олимпиаду. Для свободного входа «Возобновить новые старты» не зависит от часов и даты; для назначенного дня действует только внутри исходного окна.

«Отключить оформление» убирает декоративные главы и панораму при следующем обновлении попытки; механизмы ответов, таймер, ожидание результатов, список блюд и свидетельство продолжают работать. Если оформление мешает слабым устройствам, используйте эту кнопку. Не откатывайте сервер к версии, не поддерживающей отложенную публикацию, пока есть активное проведение.

Правильность, оценки, довольная/удивлённая реакция и свидетельство участнику закрыты. «Записано» подтверждает сохранение, а не правильность. Кухня показывает фактически выбранный состав перед нейтральным гостем. Оформление и настроение гостя не дают баллов.

## Общий финал

После закрытия входа обновите панель. Пока остаются активные попытки, публикация недоступна. Сервер завершает истёкшие попытки при обработке состояния. Последняя поздняя попытка может закончиться около 00:45 следующего дня. Когда активных попыток нет, нажмите «Опубликовать итоги». Повтор команды безопасен; отмены публикации нет.

После личного финиша студент может закрыть страницу и вернуться в том же браузере. Страница ожидания проверяет итоги раз в пять минут при открытом входе и раз в минуту после его закрытия; в скрытой вкладке опрос останавливается. Кнопка «Обновить итоги» делает проверку сразу. После публикации появляется персональный стол, разбор и свидетельство с приказом **№ 199 / 05.10.2026**.

Максимум — 51 подача и 150 баллов. Эти показатели различаются: частично верная сборка получает свои баллы, но не попадает на успешный стол. Т2 добавляет каждую верную пару отдельно. В «Что получилось на кухне» видны фактические ошибочные/частичные составы. Повторения одного блюда одной версии объединяются с сохранением всех исходных действий. Список «Все подачи» доступен без панорамы, содержит поиск и подробности.

## Совместимость и ограничения

Новые сценарные попытки: blueprint 15, storyVersion 1, assetVersion 1, отдельный runId. Старые попытки сохраняют свои варианты и прежнюю политику раскрытия. ПМ.01 не меняется. Рейтинг использует прежние критерии, отдельно для каждого проведения. Сюжет не пересчитывает сохранённые баллы.

Репозиторий остаётся публичным по решению владельца. Отложенная публикация защищает интерфейс и API, но не скрывает ранее опубликованные исходники и проверочные ключи в репозитории. Не представляйте эту меру как полную секретность банка.

## Изолированный технический стенд

Workflow `Restaurant story isolated preview` создаёт/использует только D1 `olympiad-gkts-story-preview-db` и отдельные preview-секреты. Он проходит 50, затем 60 синтетических участников, все 36 ответов, повторные запросы, восстановление и одновременное раскрытие 51 подачи. Проверяет сохранность, оценки, приватность и p95 подтверждений (цель ≤ 3 секунд). Подмена временных границ допускается только в этой отдельной тестовой D1. Production-база не используется для таких проверок.

Привязки production и preview явно разделены в `wrangler.toml` согласно [документации Cloudflare Pages](https://developers.cloudflare.com/pages/functions/wrangler-configuration/). Отчёты workflow — артефакт `restaurant-story-preview-evidence`; персональные ответы и тестовые секреты в него не входят. Персональные API имеют `private, no-store` и обходят service worker.
