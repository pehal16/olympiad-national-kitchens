# Облачное размещение олимпиады

## Что рекомендую

Для текущей версии проекта самый простой путь — один облачный сервер и браузерный доступ по ссылке.

Для этого проекта лучше использовать сервис, где можно:

- развернуть обычный Node.js-проект;
- подключить постоянный диск;
- хранить результаты централизованно.

## Лучший практический вариант

Для текущего кода самый удобный вариант — Railway с подключенным Volume.

Почему:

- проект уже запускается командой `npm start`;
- результаты сейчас хранятся в JSON-файлах;
- для JSON-файлов нужен постоянный диск;
- Railway позволяет быстро развернуть проект из GitHub.

## Что уже подготовлено в проекте

Проект теперь поддерживает отдельные каталоги хранения через переменные окружения:

- `STORAGE_DIR`
- `EXPORTS_DIR`

Это позволяет хранить попытки и выгрузки не в папке приложения, а на постоянном диске облачного сервиса.

## Пошаговый сценарий

### 1. Загрузить проект на GitHub

Нужно создать репозиторий и отправить туда папку проекта.

### 2. Создать проект в Railway

В Railway:

- создать новый проект;
- выбрать деплой из GitHub;
- выбрать репозиторий с олимпиадой.

### 3. Подключить постоянный Volume

В проекте Railway добавить Volume и смонтировать его, например, в:

```text
/data
```

### 4. Добавить переменные окружения

В Railway добавить:

```text
HOST=0.0.0.0
STORAGE_DIR=/data/storage
EXPORTS_DIR=/data/exports
YANDEX_DISK_ENABLED=true
YANDEX_DISK_OAUTH_TOKEN=ваш_токен
YANDEX_DISK_FOLDER=/Олимпиада_Национальные_кухни
```

Если нужно сменить пароль администратора, добавить:

```text
ADMIN_PASSWORD=ваш_пароль
```

### 5. Проверить запуск

После деплоя открыть выданный Railway URL и проверить:

- главную страницу;
- регистрацию участника;
- прохождение попытки;
- админ-панель;
- экспорт;
- загрузку на Яндекс Диск.

### 6. Дать ссылку участникам

Участникам выдаётся одна ссылка на олимпиаду.

Организатор использует ту же ссылку с переходом в:

```text
/admin.html
```

## Если нужен собственный адрес

Можно подключить домен или поддомен, например:

```text
olympiad.example.ru
```

Для сайта колледжа на Tilda правильная схема такая:

- основной сайт остаётся на Tilda;
- олимпиада работает на отдельном облачном адресе;
- на Tilda размещается кнопка «Пройти олимпиаду».

## Важное ограничение бесплатного размещения

Полностью бесплатные облачные сервисы либо не дают постоянный диск, либо дают временные ограничения.

Поэтому для текущего проекта бесплатный вариант возможен как тестовый или стартовый, а для стабильного проведения лучше закладывать минимальный бюджет на облако.
