# Отдельная олимпиада на Timeweb Cloud

Статус на 23 сентября 2026 года: проект «Олимпиада — Национальные кухни мира» создан отдельно от «Гастронома». Платный VPS **не заказан** по решению владельца: сначала готовим и проверяем перенос. Действующий Cloudflare Pages/D1 не переключён.

## Состав и стоимость

В форме аккаунта выбран регион Новосибирск, Ubuntu 24.04, 2 vCPU, 4 ГБ RAM, 50 ГБ NVMe, публичный IPv4 и один бэкап. Отображаемая сумма: 1,78 + 0,27 + 0,41 = **2,46 ₽/час**, около 236 ₽ за 96 часов. Проверить итог в форме заказа непосредственно перед покупкой; тариф может измениться. Дополнительные платные услуги не включать без согласования.

Timeweb списывает деньги и за выключенный сервер. Для остановки оплаты сервер, IP и другие платные ресурсы придётся удалить после выгрузки и проверки копии данных. Удалённый сервер и его бэкапы не восстанавливаются; копия должна быть за пределами VPS. При повторном создании публичный IP может измениться, значит DNS/HTTPS и доступность нужно проверить снова. [Оплата](https://timeweb.cloud/docs/service-payments/balance-top-up), [удаление сервера](https://timeweb.cloud/docs/cloud-servers/manage-servers/delete-server), [публичные IP](https://timeweb.cloud/docs/public-ip), [бэкапы](https://timeweb.cloud/docs/cloud-servers/manage-servers/backup).

## Что уже подготовлено локально

- `olympiad-server.js` открывает только страницы, статические файлы и API олимпиады. PM01 и учебный кабинет на этом сервере отвечают 404.
- `src/sqlite-d1.js` запускает существующую модель D1 на локальной SQLite-базе с WAL, транзакциями, атомарным стартом и сохранением по ревизии. Нужен Node.js 24.15+; внешняя платная база не требуется.
- `npm.cmd run verify:timeweb-local -- 40`, `-- 60 all` и `-- 60 3 finish` запускают изолированный тестовый сервер и синтетических участников. Локально 60 участников прошли все 38 синхронных раундов с 2 508 HTTP-запросами сохранения ответов, без ошибок (p95 147,7 мс). Отдельный тест 60 участников проверил 120 одновременных запросов досрочного завершения (p95 171,7 мс), тоже без ошибок. Это не проверка производительности Timeweb.
- `npm.cmd run backup:olympiad -- <абсолютный_путь_новой_копии.sqlite>` создаёт консистентную копию базы, проверяет `integrity_check`, считает попытки/события и SHA-256. Это только создание файла на том же компьютере; для защиты от удаления VPS его затем нужно скачать в независимое место и проверить там.

## До покупки и до официального запуска

1. Зафиксировать проверенную версию олимпиады без смешения с текущими незакоммиченными работами. Не направлять студентов на GitHub Pages: там сейчас только демонстрация 3D, без сохранения результатов.
2. Выбрать HTTPS-адрес. Бесплатный технический домен Timeweb допустим для теста, но Timeweb не оформляет для него SSL через панель; возможность независимого сертификата надо отдельно проверить. Для официального события нужен рабочий HTTPS без предупреждений браузера и проверка из сетей участников. [Технические домены](https://timeweb.cloud/docs/domains/technical-domain).
3. Получить отдельный SSH-ключ, серверные секреты и ограничить Node.js интерфейсом `127.0.0.1`; наружу выпускать только HTTPS через обратный прокси. Не переносить данные магазина, учебного кабинета и результаты PM01. Текущий общий `server.js` ещё импортирует их кодовые модули, но отдельный запуск закрывает их HTTP-маршруты и не требует копирования их пользовательских данных.
4. Проверить и, если есть, выборочно перенести **только** данные олимпиады из D1 с контрольными количествами/хэшами. Не переносить общую таблицу попыток целиком: в ней есть PM01.
5. Настроить резервное копирование вне VPS и проверить восстановление на новом экземпляре. Встроенный бэкап Timeweb не переживает удаление сервера.
6. На купленном VPS повторить функциональные тесты и репетицию 60 участников. Замерить CPU, RAM, диск и p95 сохранения; проверить регистрацию, старт, ответы, восстановление после обрыва, журнал преподавателя, завершение, изображения/3D и доступность из нескольких российских сетей.
7. Публичный запуск проводить только после проверки банка заданий и допуска, ограничений частоты, окна старта и организационного контроля личности. Браузер не может достоверно предотвратить скриншот или фото телефоном.

## После тестов и после события

До удаления остановить приём новых попыток, создать SQLite-копию, скачать её вне Timeweb, сверить SHA-256, попытки и события, проверить чтение на другом компьютере. Затем отдельно подтвердить удаление сервера и публичного IPv4 в панели, проверить прекращение начислений. Для следующего события создать новый VPS, восстановить базу при необходимости, вновь настроить HTTPS и повторить короткую проверку из РФ.
