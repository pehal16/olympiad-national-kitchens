# План развития ИИ-помощника преподавателя

Модель для сравнения — Qwen3.5 9B Q4_K_M через Ollama на iRU с RTX 5070 12 ГБ. Рабочий контекст составляет 16 384 токена. Сначала оцениваем текущие ответы, затем сравниваем улучшения на тех же примерах.

## 1. Контрольные работы

Подготовить около 100 проверенных преподавателем примеров по математике, физике, химии и расчётам по специальности. Включить дроби, степени, индексы, уравнения, округление, единицы и задачи с неполным условием. Для каждого примера сохранить условие, эталонную запись, допустимые преобразования и ответ. Примеры для итоговой проверки держать отдельно от материалов, которые увидит модель при дообучении.

## 2. Формулы и вычисления

- Добавить отображение формул из LaTeX в чате, предпросмотре и задании. Проверить дроби, системы уравнений, химические индексы и единицы измерения на телефоне и после сохранения работы.
- Проверять вычислимые выражения отдельным математическим модулем. Сверять численные подстановки, равносильность формул и единицы. При недостатке данных помощник запрашивает уточнение или отмечает допущение.
- Проверить на контрольных работах, исправляет ли этот подход ошибки текущей модели. Учитывать отдельно правильность вычисления, запись формулы и понятность объяснения.

## 3. Длинные лекции и продолжение разговора

Измерить на RTX 5070 режимы 16 384 и 32 768 токенов. Проверять время ответа, заполнение видеопамяти, переход на CPU и качество ответов в начале, середине и конце документа. Испытать 49 152 токена после устойчивой работы на 32 768. Выбрать режим по замерам на нескольких типах поручений. [Настройка контекста в Ollama](https://docs.ollama.com/context-length)

Разбивать лекции по разделам и страницам. Подбирать выдержки для каждого вопроса, сохранять номер страницы и извлекать формулы из исходного текста. Для длинного разговора проверять, помнит ли помощник ограничения проекта и важные уточнения через несколько сообщений. Для больших документов качество измерять по ответам и цитатам со страниц из разных частей файла.

## 4. Пробное дообучение

Если после ввода проверок и работы с контекстом останутся повторяющиеся ошибки, собрать из проверенных преподавателем решений учебный набор. Использовать материалы, разрешённые для этой цели. Для пробы обучить адаптер LoRA или QLoRA от исходных весов Qwen3.5 9B, предварительно измерив доступную память для обучения. Результат проверить отдельно от рабочего кабинета и сравнить с текущей моделью. [Карточка Qwen3.5 9B](https://huggingface.co/Qwen/Qwen3.5-9B)

## 5. Условия переключения кабинета

Предлагаемые критерии — корректное отображение всех формул из контрольного набора, не менее 95% правильных ответов в проверяемых расчётах и не менее 90% подтверждённых ответов в сценариях с длинными лекциями. Дополнительно проверить, что новый вариант сохраняет способность составлять интерактивы, задавать уточнения и править проекты. После сравнения согласовать выбранный вариант и его запуск.
